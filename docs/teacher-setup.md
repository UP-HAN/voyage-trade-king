## 0. 다른 학교 선생님께 — 이용 안내 (v0.3.1)
이 게임은 **교사 커뮤니티에 공개**되어 누구나 주소만으로 쓸 수 있습니다. 아래 '이용 안내'는 게임 타이틀 화면 맨 아래 [이용 안내] 버튼을 눌러도 똑같이 볼 수 있습니다(PRD 10.12.1과 같은 문구 — 한쪽을 고치면 다른 쪽도 고칩니다).

### 0.1 이용 안내 (화면의 [이용 안내] 창과 같은 문구)
1. 이 서버는 초등학교 교사 한 사람이 개인 비용으로 운영하는 **무료 서버**입니다. 학교·교육청·회사가 운영하는 서비스가 아닙니다.
2. 서버 사정에 따라 **예고 없이 점검하거나 멈출 수 있고**, 운영을 끝낼 수도 있습니다. 늘 쓸 수 있다고 약속드리지 못합니다. 중요한 수업에는 종이 학습지·교과서 활동을 함께 준비해 주세요. 미리 정한 점검은 화면 맨 위 띠로 알려 드립니다.
3. 서버 전체에서 동시에 열 수 있는 방은 **50개**, 같은 학교(같은 인터넷 주소)에서는 10개까지입니다. 가득 차면 방이 빌 때까지 새 방을 열 수 없습니다. 선생님 시작 화면과 판 설정의 [방 열기] 위 '사용 중인 방'에서 확인할 수 있습니다.
4. **학생 실명을 받지 않습니다.** 학생은 출석번호와 스스로 지은 회사 이름만 입력합니다. 회사 이름에 실제 이름·전화번호를 쓰지 않도록 지도해 주세요. 출석번호는 선생님 화면에만 보입니다.
5. **서버는 학생 정보를 저장하지 않습니다.** 수업 중 메시지를 전달만 하고, 서버 기록에도 출석번호·회사 이름이 남지 않습니다. 접속 제한을 위해 인터넷 주소(IP)를 서버 메모리에 잠시(최대 1시간) 두었다가 지웁니다.
6. 게임 기록은 선생님 PC 브라우저와 학생 기기에만 있다가 **24시간 뒤 자동으로 지워집니다.** [결과 파일 저장]을 누른 경우에만 선생님 PC에 파일이 남습니다.
7. 게임 속 가격·뉴스·사건은 수업을 위해 지어낸 것입니다. 교과서 내용은 쪽수를 밝혀 수업에 필요한 만큼만 인용했습니다.
8. 자주 쓰신다면 같은 프로그램을 학교 서버에 직접 설치해 쓰실 수 있습니다(설치 안내: 공개 저장소 README — https://github.com/UP-HAN/voyage-trade-king).

### 0.2 쓰기 전에 알아 두면 좋은 것
- **가입·신청이 없습니다.** 각 반의 방은 6자리 코드로 완전히 나뉩니다. 다른 학교 방 코드·학교 이름은 어디에도 보이지 않습니다.
- **사용 중인 방 n/50**: [선생님으로 시작]을 누른 뒤의 **선생님 시작 화면**과 **판 설정의 [방 열기] 위**에 지금 서버 전체에서 쓰고 있는 방 수가 보입니다. 학생도 보는 타이틀 화면과 학생 화면에는 나오지 않습니다(v0.3.4).
  - 40개부터(상한의 80%) "붐벼요"가 붙지만 [방 열기]는 그대로 쓸 수 있습니다. 50개가 차면 "가득 찼어요"가 붙고 **[방 열기] 버튼이 꺼집니다.** 판 설정은 그대로 남아 있으니 방이 비면(버튼이 다시 켜지면) 바로 열 수 있습니다. 그 시간은 교과서 활동으로 대신해도 좋습니다.
  - "확인 중…"이나 "알 수 없음"이 보이면 서버 상태를 잠시 읽지 못한 것입니다. [방 열기]는 눌러 볼 수 있고, 정말 가득 찼으면 그때 안내가 나옵니다.
  - 숫자는 최대 30초 늦게 바뀔 수 있습니다. 마지막 한 자리를 다른 선생님이 먼저 쓰면 방을 열 때 "지금 서버에 방이 가득 찼어요"가 나올 수 있습니다.
- **같은 학교에서** 동시에 열 수 있는 방은 10개, 한 시간에 새로 여는 방은 20개까지입니다. 방 코드를 많이 틀리면 학교 전체 입장이 2분쯤 막힐 수 있습니다.
- 학교 와이파이에서 접속이 되는지 **첫 수업 1주 전에** 꼭 확인해 주세요(1.1).
- 서버가 멈춘 것 같으면 화면 맨 위 공지 띠를 먼저 보세요. 학교에서 자주 쓰신다면 **학교·교육청 서버에 직접 설치**하는 방법도 있습니다(0.1의 8).

## 1. 한 번만 하는 준비 (첫 수업 1주 전, 약 25분)

### 1.1 학교 와이파이 접속 테스트 (5분)
1. 학생용 크롬북(또는 태블릿) 1대를 **학교 학생용 와이파이**에 연결합니다.
2. 게임 주소를 열고 타이틀 화면 아래 **[연결 테스트]** 를 누릅니다.
3. "연결 좋아요"가 나오면 끝입니다. 단계별 결과(웹 주소 열기 → 실시간 연결 → 서버 시각)가 모두 초록이어야 합니다.
4. "연결 안 돼요"가 나오면 학교 정보 담당 선생님께 아래 문장을 그대로 전합니다.
   > "수업용 웹 게임 주소 `https://lab.ches.es.kr` 의 접속(HTTPS)과 실시간 연결(WebSocket, 같은 주소 443 포트)을 학생용 와이파이에서 허용해 주세요. 새 포트나 프로그램 설치는 필요 없습니다."
   - 개인 도메인은 학교 유해 사이트 차단 장비에서 '분류되지 않은 사이트'로 막히는 일이 있습니다. 허용 목록에 넣으면 해결됩니다.
5. 교사 PC(교사용 망)에서도 같은 테스트를 합니다.

### 1.2 교사 PC 준비 (3분)
- 크롬 또는 엣지 최신판. 시크릿 창(InPrivate)은 쓰지 않습니다 — 새로 고침 뒤 자동 복귀에 필요한 기록이 남지 않습니다.
- **수업 시간 동안 PC 절전·화면 보호기 끄기**(Windows 설정 → 전원 → 화면·절전 '안 함'). 교사 브라우저가 게임을 계산하므로 PC가 잠들면 게임이 멈춥니다.
- TV·프로젝터를 **확장 모드**(`Win + P` → [확장])로 연결할 수 있는지 확인합니다.

### 1.3 리허설 (15분)
교사 PC + TV + 학생 기기 2~3대로 아래를 해 봅니다. (학생 기기 대신 같은 PC에 다른 브라우저 창 2개를 써도 됩니다.)
1. 타이틀 맨 아래 이용 안내 두 줄(안내 + `Copyright 2026. hanuipyo · Instagram @hanuipyo`)이 보이는지, 타이틀에 방 수가 **없는지** 확인 → [선생님으로 시작] → 선생님 시작 화면에 "사용 중인 방 n/50"이 보이는지 확인 → 판 설정: **[차시마다 한 판] → L1**, 무역 시간 **10분**, 돌발 사건 '가끔' → [방 열기].
2. [공용 화면 창 열기] → 새 창을 TV로 끌어 `F11`.
3. 학생 기기에서 주소 → [학생으로 참여] → 방 코드 6자리 → **출석번호 + 회사 이름** → 회사 설립(깃발·선장).
   - 두 번째 기기에서 **같은 회사 이름**을 넣어 "이미 다른 회사가 쓰는 이름이에요"가 나오는지 확인합니다.
4. 대시보드 [무역 시작] → 첫 라운드 거래 1번 → [일시정지]·[이어서 하기] → [+1분].
5. 학생 기기 하나의 와이파이를 껐다 켜서 **자동으로 다시 들어오는지** 확인합니다.
6. 다른 기기에서 **같은 출석번호 + 같은 회사 이름**으로 들어가 [선생님께 다시 들어가기 요청] → 대시보드 [허락]이 되는지 확인합니다.
7. 대시보드 학생 상세에서 [회사 이름 바꾸기]를 한 번 해 보고, TV 순위판에 바뀐 이름만 나오고 **출석번호는 나오지 않는지** 봅니다.
8. **교사 화면을 새로 고침**(F5)해 같은 판으로 바로 돌아오는지 확인합니다.
9. [판 끝내기] → 결산 화면 → [결과 파일 저장] → [방 닫기].

## 2. 수업 당일 (준비 약 5분)

### 2.1 교사 PC + TV
- **권장: 확장 모드.** 대시보드 창은 PC 모니터에, [공용 화면 창 열기]로 연 새 창은 TV로 끌어 놓고 `F11`(전체 화면).
- TV가 복제만 되는 교실: 대시보드 위쪽 [발표 모드]를 켜면 교사 화면이 공용 화면으로 바뀝니다. 학생 개인 정보(출석번호·자금·미접속 명단)는 공용 화면에 나오지 않습니다.

### 2.2 판 설정 (방 열기 전)
[선생님으로 시작]을 누르면 먼저 **판 단위**를 고릅니다(둘 중 하나를 꼭 골라야 하고, 다음부터는 마지막에 고른 것이 미리 골라져 있습니다).

| 판 단위 | 이럴 때 | 고르는 것 | 무역 시간(기본 25분) | 학습지 |
|---|---|---|---|---|
| **차시마다 한 판** | 교과서 차시 흐름대로 4번에 나눠서. 그날 배우는 내용만 | 차시 **L1 / L2 / L3 / L4** 중 하나 | 20~30분 권장(맛보기는 L1 10~15분) | 차시마다 다름(25분 기준 L1 '끝나고', L2 '중간마다', L3·L4 '구간 끝') + ★ 지금 쓰기(L1 ③, L4 ⑭) — 미리보기에서 확인 |
| **단원 전체 한 판** | 40분 한 번에 단원 전체를 겪게(정리·복습, 단원 도입) | 없음(L1~L4) | 25분(블록 수업은 40~60분) | 대부분 '끝나고'(항해 기록장 보며) + ★ 지금 쓰기(③·⑭) |

- 차시마다 한 판이어도 **판마다 새 회사로 시작**합니다(지난 시간 자금·화물은 이어지지 않습니다). L2·L3·L4로 시작하면 앞 차시 요약 카드가 먼저 나오고 시작 자금이 더 많습니다.
- 아직 만들어지지 않은 차시는 회색 "준비 중"으로 보입니다.
- 오른쪽 **배치 미리보기**에서 이번 판에 들어가는 활동과 **예상 수업 시간**을 보고 무역 시간을 정하세요.
- **돌발 사건**: 없음 / **가끔(기본)** / 자주. 지진·화산 같은 종류는 따로 끌 수 있습니다(재난 경험이 있는 학생이 있으면 끄기를 권합니다).
- **역전 장치**: 켬(기본) — 자산이 적은 회사에 기회 카드, 막판 대형 주문, 도약상. 규칙은 판 시작 때 학생들에게 공개됩니다.
- **순위 공개**: 상위 0/3/4/5개 회사(기본 3). 하위 순위는 어디에도 나오지 않습니다.
- 활동을 직접 고치고 싶으면 미리보기 목록에서 [넣기 / 짧게 / 빼기]를 누릅니다. 핵심 활동(1등급)은 빼지 못하고 짧게만 할 수 있습니다.
- (고급) 'L1~L2'처럼 두 차시 이상을 이어서 하고 싶으면 [고급 설정]을 펼칩니다.

### 2.3 방 열기와 학생 입장
1. [방 열기] 위의 **"사용 중인 방 n/50"** 을 확인하고 [방 열기] → **방 코드 6자리**가 공용 화면에 크게 나옵니다(주소·QR 코드 함께).
   - 버튼이 꺼져 있고 "가득 찼어요" / "점검 중이라 새 방을 열 수 없어요"가 보이거나, 눌렀을 때 "지금 서버에 방이 가득 찼어요" / "점검 중이에요"가 나오면 0.2를 보세요.
2. 학생: 주소 → [학생으로 참여] → 방 코드 → **출석번호(1~40) + 회사 이름(2~10자)** → 회사 설립(깃발·선장).
   - 미리 안내할 말: "**실제 이름은 쓰지 않아요.** 우리 회사 이름을 지어요. 친구와 같은 이름은 쓸 수 없어요. 친구를 놀리는 이름은 선생님이 막아요."
   - 쉬는 시간에 미리 들어오게 하면 시간이 절약됩니다.
3. 모두 들어오면 [무역 시작]. 무역 시계가 흐르기 시작하고, 활동이 정해진 시각에 자동으로 나옵니다(10초 전에 교사 화면에 예고 — [지금] [1분 미루기] [건너뛰기]).
4. 학생 표에는 **출석번호와 회사 이름**이 함께 보입니다(이 화면에만). 이상한 이름은 학생 상세에서 **[회사 이름 바꾸기]** 또는 **[이름 막기]**(학생이 다시 짓게 함). '이름 확인' 표시가 붙은 회사는 사람 이름처럼 보이는 회사 이름이니 확인해 주세요.
5. 다른 반 학생이나 장난 입장이 있으면 [내보내기]. 출석번호를 잘못 넣은 학생은 [번호 바꾸기]. 모두 들어왔으면 **[입장 마감]**(무역 시작 5분 뒤 자동 제안).

### 2.4 진행 중에 쓰는 버튼
| 하고 싶은 것 | 버튼 |
|---|---|
| 모두 멈추고 설명 | [일시정지] → 학생 화면 "선생님을 보세요", 시계 멈춤 → [이어서 하기] |
| 시간이 모자람·남음 | [+1] [+3] [+5] / [−1] — 뒤에 남은 활동이 자동으로 다시 배치됩니다 |
| 이 활동은 넘기기 | 타임라인 예고에서 [건너뛰기](핵심 활동이면 확인 창) |
| 돌발 사건을 직접 | 돌발 사건 패널 → [예보 보내기](다음 라운드에 일어남) |
| 학습지 쓰게 하기 | 학습지 패널 → 번호 골라 [지금 띄우기] |
| 공용 화면 바꾸기 | [자동] [순위판] [해도] [방 코드] [검은 화면] |
| 회사 이름 문제 | 학생 상세 → [회사 이름 바꾸기] / [이름 막기] |
- **교사 탭을 닫지 마세요.** 실수로 닫거나 새로 고침해도 같은 PC·같은 브라우저로 주소를 다시 열면 [이어하기]로 바로 돌아옵니다(그동안은 일시정지로 처리돼 학생 시간이 줄지 않습니다).

### 2.5 무역 시간이 끝나면 (마무리)
1. 시계가 0이 되면 진행 중인 라운드가 정산되고 마무리 단계로 넘어갑니다.
2. 차시 한 판: 결산·시상식(그 차시에서 겨룰 수 있는 상만) → 되돌아보기. **L4 판**이나 단원 전체 한 판이면 컨테이너 OX → 결산·시상식 → 되돌아보기 → (선택) 잡지 표지.
3. '끝나고 쓰기' 학습지가 있으면 공용 화면에 "오늘 쓸 학습지 번호"가 나옵니다. 학생은 자기 기기의 **항해 기록장**에서 게임 기록을 보며 씁니다(그 기기에서 24시간 동안 열 수 있어요).
4. [결과 파일 저장](**출석번호·회사 이름**·지표·상 — 필요할 때만. 실명은 들어 있지 않으니 명렬표와 대조해 쓰세요) → **[방 닫기]**.
   - 서버에는 아무 기록도 남지 않습니다. 교사 브라우저의 기록도 24시간 뒤 자동으로 지워집니다.

## 3. 학습지
- `docs/worksheet.md`의 '항해 일지'를 인쇄합니다. 게임의 "잠깐! ③" 팝업 번호와 학습지 번호가 같습니다.
- **모두 A4 단면**으로 인쇄합니다(양면 아님). L1·L2·L3은 1장씩, **L4는 2장**(L4-1: ⑬~⑯·⑱, L4-2: ⑰ 잡지 표지 원고) — 단원 전체 5장. 학생 기기의 항해 기록장 [인쇄]도 단면 기준입니다.
- **차시마다 한 판**이면 그 차시 쪽만 인쇄하면 됩니다(L1 ①~④, L2 ⑤~⑧, L3 ⑨~⑫, L4 ⑬~⑱ 두 장). 팝업도 그 차시 번호만 뜹니다.
- **단원 전체 한 판**이면 무역 시간이 짧아 팝업이 '구간 끝에 모아서'나 '끝나고' 뜹니다(기본 25분이면 거의 모두 '끝나고'). 게임은 짧은 시간에 두 섬 이야기·벽란도 같은 체험 활동을 먼저 넣고(선생님 결정: 체험 우선), 학습지는 뒤로 미룹니다. 번호는 빠지지 않으니 남은 번호는 다음 시간에 항해 기록장을 보며 마저 쓰게 하세요. 판 설정 미리보기에 "끝나고 쓸 학습지 n개"가 나옵니다. 수업 안에서 쓰게 하려면 학습지 배치를 '구간 끝'으로 직접 고르세요(그만큼 체험 활동이 짧아지거나 빠집니다).
- **★ 지금 쓰기**: 학습지를 '끝나고' 쓰는 날에도 **③의 2번(두 섬 이야기 뒤 무역의 좋은 점)** 과 **⑭의 2번(베트남 공장 결정의 까닭)** 은 체험 바로 뒤에 "잠깐! ③★ 지금 써요" 팝업이 40초 뜹니다. 학습지에 ★ 표시가 있는 칸만 그 자리에서 쓰고, 나머지 칸은 나중에 씁니다. 그 순간의 발견과 결정 까닭은 나중에 쓰면 의미가 줄기 때문입니다. 무역 시간이 아주 짧으면(단원 15분) ⑭ 지금 쓰기는 들어가지 못하고, 미리보기에 그렇게 표시됩니다.
- 종이 학습지를 쓰지 않는 날은 판 설정에서 학습지 배치를 '끄기'로 합니다.

## 4. 문제가 생기면
| 증상 | 해결 |
|---|---|
| "사용 중인 방 50/50 · 가득 찼어요"로 [방 열기]가 꺼져 있음, 또는 방을 열 때 "지금 서버에 방이 가득 찼어요" | 다른 학교 수업이 많은 시간입니다. 화면을 그대로 두면 30초마다 다시 확인해 방이 비면 버튼이 켜집니다. 오래 걸리면 교과서 활동으로 진행 |
| "사용 중인 방: 알 수 없음" | 서버 상태를 읽지 못했습니다. [다시 확인]을 누르거나 그냥 [방 열기]를 눌러 보세요. 계속되면 [연결 테스트] |
| 방을 열 때 "점검 중이에요" | 시작 화면 맨 위 공지의 시간을 확인 |
| 방을 열 때 "이 학교에서 연 방이 너무 많아요" | 같은 학교에서 동시에 연 방이 10개를 넘었거나 한 시간에 20번 넘게 열었습니다. 쓰지 않는 방을 [방 닫기]로 닫고 다시 |
| 학생이 "그런 방이 없어요" | 방 코드 6자리 확인. 여러 번 틀리면 2분쯤(반복되면 더 길게) 입력이 막히니 잠시 기다립니다 |
| 학생이 "이미 다른 회사가 쓰는 이름이에요" | 다른 회사 이름을 짓게 합니다(띄어쓰기만 다른 이름도 같은 이름으로 봅니다) |
| 학생이 "회사 이름으로 쓸 수 없는 말이 있어요" | 금칙어나 전화번호 같은 숫자가 들어 있습니다. 다른 이름으로 |
| 학생이 "이 번호는 이미 다른 회사가 쓰고 있어요" | 출석번호를 잘못 넣은 학생이 있습니다. 대시보드 '입장 문제'에서 확인 → 잘못 들어간 학생을 [번호 바꾸기], 또는 회사 이름을 잊은 학생이면 [이 기기를 7번 회사로 연결] |
| 학생이 기기를 바꿨어요 | 새 기기에서 **같은 출석번호 + 같은 회사 이름** → [선생님께 다시 들어가기 요청] → 대시보드 [허락] |
| 학생 화면 위에 "선생님 화면을 기다리고 있어요" | 교사 PC 대시보드가 꺼졌거나 인터넷이 끊김 → 교사 PC에서 주소를 다시 열어 [이어하기] |
| 학생 화면이 멈춤 | 새로 고침(같은 기기면 자동으로 다시 들어옴) |
| "새로 고침해 주세요" 안내 | 게임이 방금 새 버전으로 바뀐 경우. 학생·교사 모두 새로 고침 |
| 교사 PC를 바꿔야 함 | 원래 PC 대시보드 [판 옮기기 파일 저장] → 새 PC에서 [판 옮기기 파일 열기] (원래 PC를 쓸 수 없으면 새 판을 열어야 합니다) |
| 모두 연결이 안 됨 | [연결 테스트]로 학교 망 확인(1.1). 시작 화면의 "사용 중인 방"·공지를 확인하고, 서버 문제면 인스타그램 `@hanuipyo`로 서버 운영 선생님께 알립니다(0.1). 그 시간은 교과서·학습지 활동으로 진행합니다 |

## 5. 개인정보 안내 (가정 통신문에 쓸 수 있는 요지)
- 학생 계정을 만들지 않습니다. **학생 이름(실명)도 받지 않습니다.** 학생은 **출석번호**와 스스로 지은 **회사 이름**만 입력합니다.
- 회사 이름은 교실 TV와 친구들 화면에 보입니다. 출석번호는 **선생님 화면에만** 보입니다.
- 회사 이름에 실제 이름·전화번호·친구를 놀리는 말을 쓰지 않도록 지도하고, 게임에도 거르는 기능이 있으며 선생님이 바꾸거나 막을 수 있습니다.
- 게임 서버는 학생 정보를 저장하지 않고 수업 중 메시지만 전달합니다(서버 기록에도 출석번호·회사 이름이 남지 않습니다).
- 게임 기록은 선생님 컴퓨터와 학생 기기 브라우저에 임시로 있다가 수업 다음 날(24시간 뒤) 자동으로 지워집니다.
